# 三维虚拟工厂数字孪生系统 (V3)

本项目是一个基于 **React Three Fiber (R3F)** 构建的高保真工业级三维虚拟化演示平台。它集成了实时环境模拟、动态生产设备动画以及自动化巡航系统，旨在展示数字孪生技术在工业监控场景中的应用。

## 🚀 快速启动 (Docker)

1. 确保 Docker Desktop 已运行。
2. 在根目录执行：`docker compose up --build`
3. 访问前端：http://localhost:3000

## 🚀 核心功能

- **三维模型布局**：包含高度仿真的工业压力机（Press）、CNC 加工中心以及六轴机械臂。
- **实时天气系统**：支持“晴朗”、“雨天”、“雪天”三种天气模式的平滑切换，包含粒子物理效果。
- **昼夜交替周期**：一键切换白天与黑夜模式，动态调整全局光照、点光源及天空盒。
- **自动化视角巡航**：预设四组关键巡航点，支持在手动控制（OrbitControls）与自动平滑路径巡航之间切换。
- **数字孪生看板**：集成响应式 HUD 界面，实时显示工厂运行效率、负载、活跃设备数量等模拟数据。
- **工业美学设计**：采用暗色系工业 UI、噪点滤镜叠加以及动态扫描线动画，增强视觉深度。

## 🛠 技术栈

- **前端框架**: React 18+ (TypeScript)
- **三维渲染**: Three.js, @react-three/fiber
- **辅助组件**: @react-three/drei (用于网格、环境、粒子和相机控制)
- **样式处理**: Tailwind CSS
- **图标库**: Lucide React
- **动画**: 基于 `useFrame` 的实时逐帧动画与向量插值

## 🕹 操作指南

1. **环境控制**：通过右下角面板切换昼夜周期和天气效果。
2. **视角切换**：
   - **手动模式**：使用鼠标左键旋转、右键平移、滚轮缩放。
   - **自动巡航**：点击“自动巡航”按钮，系统将沿预设轨迹带您参观生产线。
3. **状态查看**：顶部标题栏和底部状态栏实时反馈工厂运行参数。

## 📁 目录结构

- `components/`: 包含所有三维组件（机器、环境、天气、UI等）。
- `constants.tsx`: 定义相机路径点和工厂配色方案。
- `types.ts`: 全局类型定义。
- `App.tsx`: 应用主入口及状态管理器。
