## 三、分步详解

### 步骤 1：用户交互触发 (`OverlayUI.tsx`)

#### 位置：`components/OverlayUI.tsx:40-65`

用户通过 UI 面板进行三种操作：

**1. 昼夜切换**
```typescript
<ControlBtn 
  active={state.timeOfDay === TimeOfDay.DAY} 
  onClick={() => onUpdate({ timeOfDay: TimeOfDay.DAY })}
  icon={<Sun size={18} />} 
/>
```

**2. 天气切换**
```typescript
<ControlBtn 
  active={state.weather === Weather.RAIN} 
  onClick={() => onUpdate({ weather: Weather.RAIN })}
  icon={<CloudRain size={18} className="text-blue-400" />} 
/>
```

**3. 巡航模式切换**
```typescript
<button 
  onClick={() => onUpdate({ isCruising: !state.isCruising })}
  className={state.isCruising ? 'bg-blue-600' : 'bg-white/5'}
>
  <Camera size={18} />
  <span>{state.isCruising ? '自动巡航' : '手动控制'}</span>
</button>
```

### 步骤 2：状态中枢更新 (`App.tsx`)

#### 位置：`App.tsx:12-20`

**状态初始化：**
```typescript
const [state, setState] = useState<FactoryState>({
  weather: Weather.CLEAR,
  timeOfDay: TimeOfDay.DAY,
  isCruising: false,
  activeRobotId: null,
});
```

**状态更新函数：**
```typescript
const updateState = useCallback((updates: Partial<FactoryState>) => {
  setState(prev => ({ ...prev, ...updates }));
}, []);
```

> **关键点**：使用 `Partial<FactoryState>` 支持增量更新，使用 `useCallback` 优化性能避免不必要的重渲染。

### 步骤 3：状态分发到子模块

#### 位置：`App.tsx:25-45`

状态通过 Props 传递给各个消费组件：

```tsx
<EnvironmentManager timeOfDay={state.timeOfDay} />
<WeatherManager weather={state.weather} />
<CameraCruise enabled={state.isCruising} />

{!state.isCruising && (
  <OrbitControls makeDefault maxPolarAngle={Math.PI / 2.1} />
)}
```

#### 位置：`components/EnvironmentManager.tsx:12-48`

**输入 Props：**

**状态响应逻辑：**

| 状态 | 影响元素 | 白天值 | 夜晚值 |
|------|---------|--------|--------|
| `timeOfDay === DAY` | Sky 太阳位置 | `[10, 10, 10]` | `[0, -10, -10]` |
| | Sky inclination | `0` | `0.6` |
| | Stars 组件 | 隐藏 | 显示 (5000 颗) |
| | Cloud 组件 | 显示 | 隐藏 |
| | ambientLight 强度 | `0.4` | `0.1` |
| | directionalLight 强度 | `1.2` | `0.2` |
| | 工厂顶灯强度 | `0.2` | `0.8` |
| | 蓝/橙色氛围灯 | `0` | `0.5` |

**核心代码：**
```typescript
const isNight = timeOfDay === TimeOfDay.NIGHT;
const sunPos: [number, number, number] = isNight ? [0, -10, -10] : [10, 10, 10];

return (
  <>
    <Sky sunPosition={sunPos} inclination={isNight ? 0.6 : 0} />
    {isNight && <Stars count={5000} />}
    {!isNight && <Cloud opacity={0.5} />}
    
    <ambientLight intensity={isNight ? 0.1 : 0.4} />
    <directionalLight position={sunPos} intensity={isNight ? 0.2 : 1.2} />

    <pointLight position={[10, 5, 10]} intensity={isNight ? 0.5 : 0} color="#63b3ed" />
    <pointLight position={[-10, 5, -10]} intensity={isNight ? 0.5 : 0} color="#ed8936" />
  </>
);
```

### 4.2 气象效果模块 (`WeatherManager.tsx`)

#### 位置：`components/WeatherManager.tsx:11-68`

**输入 Props：**
```typescript
interface WeatherManagerProps {

}
```

**状态响应逻辑：**

| 天气状态 | 粒子系统 | 下落速度 | 水平漂移 | 粒子大小 | 颜色 |
|---------|---------|---------|---------|---------|------|
| `CLEAR` | 不渲染 | - | - | - | - |
| `RAIN` | 2000 粒子 | `0.8` | `0` | `0.1` | `#93c5fd` |
| `SNOW` | 2000 粒子 | `0.2` | `0.05` | `0.2` | `#ffffff` |

**逐帧动画逻辑 (`useFrame`)：**
```typescript
useFrame((state, delta) => {
  if (weather === Weather.CLEAR) return;
  
  const speed = weather === Weather.RAIN ? 0.8 : 0.2;
  const drift = weather === Weather.RAIN ? 0 : 0.05;

  for (let i = 0; i < count; i++) {
    // Y轴下落
    positions[i * 3 + 1] -= speed;
    // 雪花X轴飘动
    if (weather === Weather.SNOW) {
      positions[i * 3] += Math.sin(state.clock.elapsedTime + i) * drift;
    }
    // 超出地面重置位置
    if (positions[i * 3 + 1] < 0) {
      positions[i * 3 + 1] = 40;
    }
  }
  meshRef.current.geometry.attributes.position.needsUpdate = true;
});
```

### 4.3 相机控制模块 (`CameraCruise.tsx`)

#### 位置：`components/CameraCruise.tsx:11-38`

**输入 Props：**
```typescript

```

**状态响应逻辑：**

| `isCruising` 值 | OrbitControls | CameraCruise 动画 | 相机控制权 |
|----------------|---------------|------------------|-----------|
| `false` | ✅ 启用 | ❌ 跳过 | 用户手动控制 |
| `true` | ❌ 不渲染 | ✅ 运行 | 自动路径巡航 |

**路径点配置 (`constants.tsx:3-9`)：**
```typescript
export const CAMERA_PATH: CameraWaypoint[] = [
  { position: [20, 15, 20], lookAt: [0, 0, 0] },      // 全景概览
  { position: [-20, 10, 10], lookAt: [5, 2, -5] },    // A侧生产线
  { position: [0, 8, -20], lookAt: [0, 2, 0] },       // 后方质检区
  { position: [15, 5, 5], lookAt: [-10, 0, 10] },     // 机械臂细节
];
```

**核心巡航逻辑：**
```typescript
useFrame((state, delta) => {
  if (!enabled) return;  // 关键：状态开关

  // 线性插值平滑移动
  camera.position.lerp(targetPos.current, delta * 0.5);
  camera.lookAt(lookAtPos.current);

  // 到达后切换到下一路径点
  if (camera.position.distanceTo(targetPos.current) < 1) {
    const nextIdx = (waypointIndex + 1) % CAMERA_PATH.length;
    setWaypointIndex(nextIdx);
    targetPos.current.set(...CAMERA_PATH[nextIdx].position);
    lookAtPos.current.set(...CAMERA_PATH[nextIdx].lookAt);
  }
});
```

## 六、关键设计要点

### 6.1 单向数据流原则

- **单一数据源**：所有状态集中在 `App.tsx` 的 `useState` 中
- **状态只读**：子组件只能通过 `onUpdate` 回调请求修改
- **纯函数更新**：使用扩展运算符 `{ ...prev, ...updates }` 保证不可变性

### 6.2 性能优化

1. **条件渲染**：`WeatherManager` 在 `CLEAR` 状态返回 `null`，避免不必要计算
2. **有条件挂载**：`OrbitControls` 仅在非巡航模式渲染
3. **`useCallback`**：`updateState` 函数被记忆化，避免子组件不必要重渲染
4. **`useMemo`**：粒子初始位置只计算一次 (`WeatherManager.tsx:14-21`)

### 6.3 响应式设计

- 所有模块通过 Props 接收状态，与状态源解耦
- 易于扩展：新增状态只需在 `FactoryState` 添加字段，在 `App.tsx` 传递
- 易于测试：各模块可独立接收 Props 进行单元测试

## 七、扩展建议

如需新增功能（如：雾效、季节系统），可遵循相同模式：

1. 在 `types.ts` 扩展枚举和 `FactoryState`
2. 在 `OverlayUI` 添加控制按钮
3. 创建新的 Manager 组件或扩展现有组件
4. 在 `App.tsx` 中通过 Props 传递状态
