# 浮层控制→环境/气象/相机 状态数据流说明

## 1. 全局状态模型

状态在 `App.tsx:13-18` 中以单一 `useState` 持有，类型定义为 `FactoryState`：

```typescript
// types.ts:13-18
interface FactoryState {
  weather: Weather;       // CLEAR | RAIN | SNOW
  timeOfDay: TimeOfDay;   // DAY | NIGHT
  isCruising: boolean;
  activeRobotId: string | null;
}
```

**唯一修改路径**：`App.tsx:20-22` 的 `updateState` 回调，接收 `Partial<FactoryState>` 进行浅合并：

```typescript
const updateState = useCallback((updates: Partial<FactoryState>) => {
  setState(prev => ({ ...prev, ...updates }));
}, []);
```

## 3. 三条核心数据流分步说明

### 3.1 昼夜切换 → 环境光照

**触发入口**：`OverlayUI.tsx:34` / `OverlayUI.tsx:39`

```
用户点击 ☀️/🌙 按钮
    │
    ▼
onUpdate({ timeOfDay: TimeOfDay.DAY 或 TimeOfDay.NIGHT })
    │
    ▼
App.tsx: setState(prev => ({ ...prev, timeOfDay }))
    │
    ▼ (React re-render, props 更新)
EnvironmentManager 接收新的 timeOfDay
    │
    ▼ (EnvironmentManager.tsx:13)
isNight = timeOfDay === TimeOfDay.NIGHT
    │
    ├─► Sky 组件: sunPosition 切换
    │       DAY → [10, 10, 10]    (天空亮, 日照)
    │       NIGHT → [0, -10, -10] (天空暗, 日落线下)
    │
    ├─► Stars: 仅 NIGHT 渲染 <Stars /> (5000颗, radius=100)
    │
    ├─► Cloud: 仅 DAY 渲染 <Cloud /> (opacity=0.5)
    │
    ├─► ambientLight 强度
    │       DAY → 0.4    NIGHT → 0.1
    │
    ├─► directionalLight 强度 + 位置
    │       DAY → intensity=1.2, position=[10,10,10]
    │       NIGHT → intensity=0.2, position=[0,-10,-10]
    │
    └─► 室内 pointLight (模拟工厂灯光)
            中心灯: DAY=0.2 → NIGHT=0.8
            蓝色灯(10,5,10): DAY=0 → NIGHT=0.5
            橙色灯(-10,5,-10): DAY=0 → NIGHT=0.5
```

**关键逻辑位置**：`components/EnvironmentManager.tsx:12-49`

### 3.2 天气切换 → 气象粒子效果

**触发入口**：`OverlayUI.tsx:50` / `OverlayUI.tsx:55` / `OverlayUI.tsx:60`

```
用户点击 ☀️/🌧️/❄️ 按钮
    │
    ▼
onUpdate({ weather: Weather.CLEAR / RAIN / SNOW })
    │
    ▼
App.tsx: setState(prev => ({ ...prev, weather }))
    │
    ▼ (React re-render, props 更新)
WeatherManager 接收新的 weather
    │
    ▼ (WeatherManager.tsx:48)
weather === CLEAR ? return null : 渲染粒子
    │
    ├─► CLEAR: 不渲染任何粒子，return null
    │
    ├─► RAIN:
    │     粒子数: 2000
    │     下落速度: 0.8 (快速直线下落)
    │     水平漂移: 0 (无)
    │     粒子大小: 0.1
    │     粒子颜色: #93c5fd (浅蓝色)
    │     透明度: 0.6
    │
    └─► SNOW:
          粒子数: 2000
          下落速度: 0.2 (缓慢)
          水平漂移: sin(elapsedTime + i) * 0.05 (随风飘动)
          粒子大小: 0.2
          粒子颜色: #ffffff (白色)
          透明度: 0.6
```

**关键逻辑位置**：
- 粒子初始化: `components/WeatherManager.tsx:15-23` (useMemo, 仅计算一次)
- 每帧动画: `components/WeatherManager.tsx:25-46` (useFrame)
- 条件渲染: `components/WeatherManager.tsx:48` (CLEAR 返回 null)

## 5. 设计特征

| 特征 | 说明 |
|------|------|
| **单向数据流** | 状态仅从 App 向下流动，子组件不反向修改 state |
| **单一状态源** | `FactoryState` 集中在 `App.tsx`，无分散状态 |
| **浅合并更新** | `updateState(Partial<...>)` 允许只更新部分字段，其余字段保持不变 |
| **半条件渲染** | `CameraCruise` 始终挂载（通过 `enabled` 控制逻辑），`OrbitControls` 条件渲染（仅手动模式挂载），避免两者同时操控相机 |
| **即时响应** | 所有状态变更在下一帧 React re-render 中生效，无异步延迟 |
| **帧级动画** | `WeatherManager` 和 `CameraCruise` 通过 `useFrame` 在渲染循环中逐帧更新，与状态解耦 |
